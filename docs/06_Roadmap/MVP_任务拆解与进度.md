## Phase 1: 基础设施与数据底座 (已完成 ✅)
- [x] **架构选型与环境搭建**：React + Vite + TypeScript 前端脚手架，本地 Supabase 容器化后端。
- [x] **数据库 Schema 定稿**：完成 37 张核心表、视图及枚举类型的设计（V4.1）。
- [x] **种子数据注入**：编写 Python 数据清洗脚本，将真实的 Excel 补课学生数据解析并安全导入 `students_info` 等表。
- [x] **全栈联调起步**：前端引入 `@supabase/supabase-js` 与 `zustand` 状态管理。完成全局学生数据流（包含 RLS 临时放通策略），成功渲染真实数据至大盘。

## Phase 2: 核心前端页面与 CRUD (已完成 ✅)
- [x] **学生档案详情页 (Profile Detail)**：点击学生列表后，进入详情页，展示其签证、课程、紧急联系人、风险记录。
- [x] **动态筛选与搜索**：实现学生列表的学校、风险等级、在读状态的组合条件查询。
- [x] **统一鉴权与 RLS 收紧**：
  - 前端搭建基于 Supabase Auth 的登录/登出页面。
  - 后端回收匿名 (Anon) 访问权限，针对 `admin`, `manager`, `tutor` 角色编写严密的 Row-Level Security 策略。

## Phase 3: 业务工作流 (进行中 🚀)
- [x] **全量原型覆盖**：完成侧边栏全部 18 个页面的 React 路由与页面组件注册。
- [x] **住宿与风险流**：实现宿舍床位分配展示（接入真实数据）与全体风险大盘。
- [x] **辅助管理流**：实现接送、家校沟通、签证预警、财务账单的 UI 对接。
- [x] **教务选课流**：选课与建档闭环（Phase 23 修复 + 新建学生弹窗 + 核心科目自动补登记 backfill，2026-07-10）。

- [x] **学业跟踪深化**：课时按课型双池（Phase 19）、考核节点与加权总评（Phase 24）、报告系统（出勤两周/学术月 + Word 导出，Phase 25）、学习跟进（Phase 27）。
- [x] **学生生命周期**：阶段与服务费用面板、文件矩阵总览、服务截止日期排序筛选（2026-07-07 ~ 07-09）。
