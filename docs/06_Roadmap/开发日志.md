### 🏗️ 架构改动

#### `src/store/useAcademicStore.ts`
- **新增接口**: `AcademicMilestone`、`CourseAsset`、`GradeRecord`、`Course`
- **新增方法**:
  - `fetchMilestones` / `createMilestone` / `deleteMilestone`
  - `createProgramSubject` / `updateProgramSubject` / `deleteProgramSubject`
  - `fetchCourses`
  - `fetchCourseAssets` / `topUpHours`
  - `fetchGradeRecords` / `addGradeRecord`
- **重要逻辑**: `generateTimetable` 优先读取 `program_subjects.default_schedule` 生成真实课表，无配置时才回退到随机算法

#### `src/store/useStudentStore.ts`
- **`fetchStudents` 重写**: 改为从 `profiles` 出发（两步查询+JS合并），确保无 `students_info` 行的学生（如通过住宿页新建的学生）也能在列表中显示，解决 406 / FK 歧义错误
- **`fetchStudentById` 重写**: 改为两步查询（profiles + students_info maybeSingle），支持新生打开档案页而不报错
- **新增 `updateStudent`**: 使用 `upsert` 写入 `students_info`，无档案自动创建、有档案自动更新

#### `src/store/useScheduleStore.ts`（全新）
- **新文件**: 完整的排课状态管理
- `fetchTutors` — 获取全部 tutor/admin 账号作为可选老师
- `fetchSchedules` / `fetchPendingSchedules` — 分别拉取已审批/待审批列表
- `createSchedule` — 创建 `pending_approval` 状态的排课申请
- `approveSchedule` — 审批通过：更新状态 → **写入 `schedule_changes` 审批日志**（含 `approver_id`）→ 自动扣减 `course_assets` 课时余额
- `rejectSchedule` — 拒绝并删除申请

### 📐 业务流程变更

#### 奥大课程双轨并行架构（已完整落地）

```
Admin 配置科目底表 (program_subjects)
  └── 含固定上课时间段 (default_schedule)
      └── 学生选课 → 一键生成真实课表 (school_timetable)
          └── 辅导老师创建 1v1 排课申请
              └── 教务审批通过
                  ├── schedule_changes 审批日志（含 approver_id）
                  ├── schedules.status → 'scheduled'
                  └── course_assets.used_hours += 课时时长
```
