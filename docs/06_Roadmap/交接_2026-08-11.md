## 四、坑与约定（新会话必读）

1. **PostgREST 嵌套查询一律显式写外键**：`profiles!student_id(full_name)`。19 张表有多个 FK 指向 `profiles`，加新外键会让该表所有裸嵌套立刻失效，且 tsc/build/migration 都不报错。
2. **改视图列名或列序必须 `drop view` + `create view`**，`create or replace view` 会报 ERROR 42P16。
3. **验证以 `npm run build` 为准**。
4. **写 SQL 脚本时 heredoc 要用 `<<'PY'`**（带引号），否则 shell 会把 PL/pgSQL 的 `$$` 展开成进程号。或用 `$DOBLK$` 这类具名标签。
5. **`profiles` 插入 role='student' 会触发 `trg_auto_create_students_info` 自动建 students_info 行**，再手动 INSERT 会撞主键，要用 upsert。
6. **数据源可信度**：库 > 《本项目学生名单》>《动态表格_nfe.xlsx》。动态表格已知错误：吴弈辉（应为吴奕辉）、含占位行「潜在男生」、绿通那批结束日期早于开始。
7. **学号语义**：号码=进入项目先后，退出者占号、永不回收重排。但顺序表本身非严格时间序（吴奕辉 2021 入读却排 13 位），不宜当作严格先后使用。
8. **风险分存库**，改引擎后需在 `/risk` 页点「重算全体风险分」才对存量生效。
