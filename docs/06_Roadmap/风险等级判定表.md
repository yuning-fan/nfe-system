# 风险等级判定表（红/黄灯口径）

> 更新：2026-06-26　依据：`src/lib/riskEngine.ts`（口径以代码为准）
> 用途：快速对照"学生为什么红/黄"，以及以后调参的参照表。

## 一、判定总则
- 满分 **100**，扣分制，统计**近 15 天滚动窗口**。
- 判定优先级：
  1. **硬触发**：命中任意一条 → 直接 🔴红（与分数无关）。
  2. 否则按分数：**<60 → 🔴红**；**60–84 → 🟡黄**；**≥85 → 🟢绿**。
  3. **黄灯底线**：官方出勤率 <97% 时，即使分够绿也至少压到 🟡黄。

## 二、🔴 红灯

### A. 硬触发（命中即红，与分数无关）
| 条件 | 录入来源 |
|---|---|
| 连续缺勤（学校上课）≥ 3 天 | 生活 · 早上出勤 |
| 官方出勤率 < 95%（违反合约线） | 巡查 · 出勤率录入 |
| 学校警告信 ≥ 3 封（达劝退评估，人工复核） | 学管 · 学校警告信 |
| 内部警告信累计 ≥ 3 封（严重违约） | 三步走审批 |
| 证件 ≤ 7 天到期 | 学生档案 · 证件 |

### B. 扣分扣到 <60
多项扣分叠加（缺勤/违规/警告信/欠费等），把 100 扣到 60 以下。

## 三、🟡 黄灯
| 条件 | 说明 |
|---|---|
| 分数 60–84（累计扣 16–40 分） | 中度累积 |
| 官方出勤率 96.x%–<97%（逼近合约线） | 黄灯底线，强制至少黄 |

## 四、扣分明细表
| 扣分项 | 扣分 | 录入入口 |
|---|---|---|
| 晚自习缺勤 | 每次 −8 | 巡查 · 晚自习点名 |
| 学校上课缺勤 | 每次 −8 | 生活 · 早上出勤 |
| 辅导课缺勤（无故） | 每次 −8 | 辅导 · 销课 |
| 查寝异常（标缺席） | 每次 −8 | 生活 · 查寝 |
| 违规-缺席自习 | −8 | 违规登记 |
| 违规-手机/睡觉/闲聊 | 各 −5 | 违规登记 |
| 违规-晚归未报备 | −5 | 违规登记 |
| 违规-严重违纪 | −10 | 违规登记 |
| 违规-学术不端 | −10 | 违规登记（+上传附件） |
| 内部警告信累计 | 第1封 −10、第2封再 −20、第3封→直接红 | 三步走 |
| 证件临期 | ≤30天 −5 / ≤14天 −10 / ≤7天 −20（且红） | 证件 |
| 欠费 | −10（存在未缴即扣） | 费用 |
| 科目加权均分低于该科过线分 | 每科 −6 | 成绩录入 |

## 五、说明
- **红线信号**（亮红但不直接扣分）：官方出勤率、学校警告信累计、连续缺勤、证件≤7天。
- **扣分项**：累积压低分数→影响等级。
- 以上**阈值与各项扣分均为代码常量**（`riskEngine.ts` 的 `DEDUCT`/`GRADE_THRESHOLD` 及等级映射），尚未做成系统配置页可调。调参需改代码，或后续做配置页。
- 双红线：NFE 合约线 出勤率 95%（先亮）、学校线 93%；详见《警告信与预警体系_设计.md》。
