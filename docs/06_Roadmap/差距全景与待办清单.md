## 关键依赖链 & 建议优先级

- **学生端是多个功能的源头**：交作业 → 资料库推送脱敏 / 作业核查；请假申请 → 学管/生活待审批。
- **P0 决策**：①家长/学生端定**微信小程序还是 H5**；②员工工作台是**独立 H5** 还是**并入现有 web 按角色切换**。这两个决定后续全部工作量。
- **建议顺序**：P0 形态决策 → 员工高频工作流（辅导上课记录 / 巡查点名+违规 / 生活药物·出勤，表已就绪）→ 学生端（解锁作业流）→ 家长端 → admin 占位页。
